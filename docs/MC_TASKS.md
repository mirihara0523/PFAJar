# 수정본 작업 목록

우선순위는 현재 작업 순서를 위한 분류입니다.

## 높음

- [x] **소스와 수정본 실행 파일 대조·통합**: 내부 버전은 모두 `7.0.2-MC.1`이었지만 `main.js`, `py/czi_extract.py` 등에 내용 차이가 있어 수정본 기능을 소스에 반영했다. 검증용 실행본은 별도 폴더에 빌드한다.
- [x] **CZI 이미지 전체 보관 및 재복사 최소화**: Z 평면을 순차 처리하고 TIFF를 순차 저장하도록 변경했다. 8비트 변환 시 불필요한 `float64` 중간 배열 생성을 줄였다. 실제 RAM 감소 효과는 `MASONJAR_PERF=1` import로 검증한다.
- [x] **MAX 전체 스택 일괄 읽기 개선**: 지원되는 TIFF에서 평면별 최댓값 누적 처리를 추가했다. 실제 대용량 데이터에서 최대 RSS를 확인한다.

완료된 높음 우선순위 항목은 새 import와 성능 로그로 효과를 확인한다.

## 중간

- [x] **성능 로그 비교 표 개선**: 이전/새 import를 별도 로그로 집계하고 단계별 시간·메모리 증감률을 계산한다. 후속 최적화의 기준 자료로 사용한다.
- [x] **import 결과 자동 검증 강화**: TIFF 누락·0바이트 파일·점 포함 파일명·manifest를 검사하고, 예상 TIFF 수·점 포함 파일 수·최소 파일 크기 조건을 지정해 출력 수를 검증한다.
- [x] **화면 담당 프로세스의 동기식 입출력 개선**: heartbeat는 비동기 registry 갱신으로 분리하고, 화면 상태는 1.5초 캐시를 사용해 반복 파일 읽기를 줄였다. 추가적인 전체 상태 계산 비동기화는 측정 결과에 따라 검토한다.

## 낮음

- [x] **검출 작업의 모델 재로드 최소화 조사**: `find_neurons.py`는 실행 1회당 `AutoDetectionModel.from_pretrained()`를 한 번만 호출하고 모든 입력 이미지를 재사용한다. 반복되는 별도 검출 작업 사이의 모델 재사용은 장수 프로세스·메모리 상주 비용을 비교해야 하므로 현재 변경하지 않는다.

- [x] **CZI import 5단계 Orient 제목 가림**: 회전 viewport를 고정 clipping 영역에 배치해 파일 제목을 가리지 않도록 수정했다. 추가 UI 회귀 검증은 후속 진행한다.
  - 재현 조건: `Import from Zeiss CZI` 과정의 5. Orient 단계에서 이미지 회전
  - 등록일: 2026-09-09
  - 원인 후보: 회전 시 `viewport`에 CSS `transform`을 적용하지만 transform은 레이아웃 높이를 다시 계산하지 않는다. `.czi-orient-tile`에 overflow 제한이 없어 회전된 미리보기의 시각적 영역이 앞의 제목 영역까지 침범할 수 있다.
  - 관련 코드: `js/czi_wizard.js`의 `renderOrientationGrid()`, `css/theme.css`의 `.czi-orient-tile-viewport`.
  - 적용 내용: 회전 viewport를 별도 고정 영역 안에 배치하고 `overflow: hidden`으로 clipping했다.
