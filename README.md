# PFA Jar

This folder contains the source code dedicated to the PFA Jar, modified version of Mason Jar. The original source code and the original executable are preserved separately. For information on paths, restoration history, and verification methods, please refer to [the Modified Source Setup Guide](docs/MC_SOURCE_SETUP.md).

# Introduction

PFA Jar is a fork of [Mason Jar](https://github.com/matsojr22/masonjar) for neurohistology analysis of the mouse brain.


# Requirements

- At least 20GB of disk space
- 32GB of memory MINIMUM (64GB recommended)
- Intel i5 / Apple Silicon / AMD Ryzen 4th gen
- (REQUIRED) GPU with at least 6 GB of VRAM and CUDA 11 support

# Install from Release

Download the most recent release from [mirihara0523/PFAJar release](https://github.com/mirihara/pfajar/releases).
