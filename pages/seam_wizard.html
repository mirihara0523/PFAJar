Seam Correction

Removes leftover vertical tile-stitching seams (periodic brightness steps) from a slide image. Detection is automatic; only the averaging band around each seam is adjustable. This is a separate step from BaSiC shading correction — BaSiC removes smooth vignetting, this removes the discrete tile-boundary step BaSiC can't model.

DAPI is corrected by default. Check any additional signal branches to include them in this same run -- each channel is corrected into its own output folder.
