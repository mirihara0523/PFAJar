What's new

Advanced

Mason Jar does not contact GitHub at startup and never requires an update automatically. Use “Check again” to check this build's GitHub releases manually.

When enabled, Mason Jar may offer beta builds marked pre-release on GitHub. Stable releases are still preferred when they are newer.

When enabled, Update Now copies the whole install folder next to itself (name ends with .backup-<oldVersion>) before replacing files. Off by default — backups use a lot of disk.

—

Notes

  • On Windows, use Update Now to download and install in one step. macOS users can download the DMG from GitHub.
  • Mason Jar must restart to finish installing. Finish or cancel long Python jobs first. Close other copies of Mason Jar first.
  • You can keep the app in any folder name (including Explorer’s versioned unzip folder). Updates replace files in place.
  • Installs on read-only or network paths may fail — use Open release page and install manually if needed.
  • Pre-releases and version backups are off by default.
