Isolate Regions


Outputs the ROIs for a given Mason Jar aligned brain. The ROI pacakges are only compatible with custom graphin tools at this time. The output is a series of .pkl files that contain the intensity, verticies, and region info. To use select the directory with the intensity images (named in the same scheme as the Mason Jar aligned images), the brain annotation pkls, and your output directory. Each slice uses the Align annotation PKL for that slice (e.g. Annotation_M528_s061.pkl for M528_s061.ome.tiff), not list order alone. Optionally include a folder of low-resolution DAPI images with the same filename stem as each intensity image (.png, .tif/.tiff, .jpg, or <stem>_dapi.png / _dapi.tif). DAPI is resized to the intensity grid and stored as dapi_roi in each PKL for dual-channel export. If the DAPI folder is selected but no matching file exists for a slice, that slice's PKLs will omit dapi_roi (check the Log for warnings). Select whole or hemisphere only (whole-brain mode keeps the left half of each slice). Use Configure outputs to pick CCF regions in the wizard.
